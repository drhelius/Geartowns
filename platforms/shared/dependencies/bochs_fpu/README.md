# Bochs x87 arithmetic for Geartowns

The floating point arithmetic of the 80387 unit: Berkeley SoftFloat 3e as adapted for Bochs
(https://github.com/bochs-emu/Bochs), with the Bochs x87 extensions, taken from `bochs/cpu/softfloat3e` and
`bochs/cpu/fpu` on the `master` branch at commit `78973ff57711cf95d964566fab13e360a82e2423` (October 2026).

Bochs's SoftFloat passes a `softfloat_status_t` to every operation instead of using global state, and adds what the
x87 needs over upstream SoftFloat: the denormal operand flag, the C1 rounding-up indication, unsupported extended
formats, masked and unmasked underflow and overflow results, and the 80-bit rounding precision control.

`bochs_fpu.h` and `bochs_fpu.cpp` are generated by `amalgamate.py` and not edited by hand:

- `bochs_fpu.h` holds `softfloat.h` and `fpu/fpu_trans.h` with the headers they include;
- `bochs_fpu.cpp` holds the sources and the remaining headers;
- every file keeps its license notice, and a `/* bochs/cpu/... */` line marks where it starts.

Only the sources the Bochs x87 implementation needs are kept (the `SOURCES` list in the script): the extended
precision operations, the conversions from and to single, double, int32 and int64, the 128-bit operations the
transcendental functions use, the 8086-SSE NaN rules for those formats, and the transcendental functions and
partial remainder from `fpu`. The list is the link closure of the SoftFloat calls in Bochs's `fpu_*.cc`, with and
without `__int128` and `__builtin_clz`.

Licenses:

- SoftFloat 3e: BSD-3, see `COPYING.txt`;
- the `fpu` files: extensions to SoftFloat 2b written for Bochs, under the SoftFloat 2b notice kept in each file;
- `fpu_trans.h`: LGPLv2.1 or later, see `COPYING.LESSER`.

## Changes

No line of Bochs's code is changed. The script only:

- inlines every quoted include once, where it first appears;
- replaces `config.h`, which Bochs's `configure` generates, with `CONFIG`: the `BitNN` types, `BX_CONST64`,
  `BX_CPP_INLINE`, `BX_LITTLE_ENDIAN` from the same macros as `src/common/defines.h`, `__int128` and
  `__builtin_clz` when the compiler has them, and the options of Bochs's `softfloat3e/Makefile.in`;
- defines `FLOAT128` there, which the `fpu` sources define before including `softfloat-specialize.h`, because that
  header is now inlined once for all of them.

## Updating

Check out Bochs at the new commit and run `python3 amalgamate.py <path to the checkout>`. It rewrites the two files
and the license copies in this directory, with the commit in the first line of each file. Add sources to `SOURCES`
if Bochs's x87 code calls new SoftFloat functions.
